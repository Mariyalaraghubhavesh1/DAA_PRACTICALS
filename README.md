# 💻 Design and Analysis of Algorithms – Lab Practicals

Welcome to my **Design and Analysis of Algorithms (DAA) Lab Practicals** repository!

This repository contains 12 practical implementations of fundamental algorithms using **C++**. It is developed as part of the Computer Science and Engineering academic curriculum to understand algorithm design, implementation, problem-solving techniques, and performance analysis.

## 🎯 Objectives

- Understand fundamental algorithm design techniques.
- Implement and analyze sorting and searching algorithms.
- Explore recursion and dynamic programming.
- Understand graph algorithms and traversal techniques.
- Study time and space complexity.
- Develop efficient problem-solving and programming skills.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** GCC / G++
- **Standard:** C++17
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project in Visual Studio Code.

3. Navigate to the practical folder.

4. Compile the C++ program:

   ```bash
   g++ -std=c++17 program.cpp -o program
   ```

5. Execute the program:

   ```bash
   ./program
   ```

   On Windows:

   ```bash
   program.exe
   ```
